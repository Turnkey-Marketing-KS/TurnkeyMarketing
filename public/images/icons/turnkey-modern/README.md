## Generation brief

Contemporary geometric, vector-like website icons with mostly flat matte shapes, bold silhouettes, consistent navy outlines, and restrained depth. The palette uses Turnkey navy `#232E66`, key blue `#3F8CCB`, green `#93C845`, and off-white `#F4F2ED`. Each icon contains one centered concept with no text, brand logo, watermark, frame, or background scene.

The labeled 30-icon review board is saved at `outputs/icon-concepts/turnkey-modern-icon-concepts-30.jpg`.

Matching high-contrast alternates for dark navy backgrounds are available in `../turnkey-modern-on-navy/`.
