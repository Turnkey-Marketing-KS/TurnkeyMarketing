# Turnkey modern icons for navy backgrounds

Thirty transparent 512×512 lossless WebP alternates for use on Turnkey navy and other dark brand surfaces.

Each file has the same filename, canvas size, artwork, and transparent background as its light-background counterpart in `../turnkey-modern/`. The original icon remains intact, including all navy internal structure. A restrained 8px exterior keyline in Turnkey off-white (`#F4F2ED`) separates the silhouette from dark backgrounds without flattening the artwork.

Use this directory when an icon is displayed on `#232E66`, `#1A2352`, charcoal, or another dark section. Use `../turnkey-modern/` on white, cream, and off-white sections.

The labeled review board is saved at `outputs/icon-concepts/turnkey-modern-icon-concepts-30-on-navy.jpg`.
