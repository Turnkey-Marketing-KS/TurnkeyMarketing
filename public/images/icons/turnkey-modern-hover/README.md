# Turnkey modern hover icons

These six transparent WebP assets are high-contrast hover-state companions to the matching icons in `turnkey-modern/`:

- `consultation.webp`
- `direct-mail.webp`
- `social-media.webp`
- `customer-retention.webp`
- `local-seo.webp`
- `digital-ads.webp`

They preserve the modern navy-and-lime illustration language while replacing the dominant medium-blue fills with warm white or pale blue for contrast on the homepage service-card hover background.
