# Agent brief: direct-mail SEO defense and consolidation

## Mission

Direct mail is already well represented by:

- Commercial owner: `/services/direct-mail`
- Informational owner: `/resources/direct-mail-for-repair-shops`

The export reports zero volume for the qualified terms in this snapshot. Treat this as an optimization and cannibalization-defense assignment, not a reason to delete a valuable service or create more pages.

## Phase 0 — query and overlap audit

1. Export Search Console queries and landing pages for both URLs.
2. Compare title, description, H1, headings, introductions, schema, links, and CTA paths.
3. Confirm the service page owns managed-service intent and the guide owns campaign-learning intent.
4. Inventory approved examples for list strategy, offers, timing, creative, order verification, call tracking, repeat drops, and follow-up.

## Phase 1 — commercial page

Strengthen `/services/direct-mail` around managed campaign execution:

- list/audience strategy;
- offer and creative;
- timeline and order verification;
- budget/process responsibility;
- tracking and penetration reporting;
- fit/not-fit;
- visible FAQs.

Keep Service/FAQ/Breadcrumb schema aligned with visible content. Link to the guide with a descriptive educational anchor.

## Phase 2 — guide

Strengthen the existing guide around planning and evaluation. It should explain why the list, offer, timing, repeated exposure, phone handling, and retention follow-up matter. Expand `auto repair mailer ideas` as a section before considering another URL.

Link to the service with `service_cta_click`, `data-track-slug="direct-mail"`, and a resource-specific placement.

## Phase 3 — proof and links

Add approved campaign examples and documented Results links. Distinguish correlation from attribution. Pursue relevant printer, association, or partner links only where Turnkey adds original methodology.

## Phase 4 — cannibalization decision

Review query overlap after 60–90 days. If both URLs rank for the same terms, sharpen intent signals and anchors first. Merge only if one page has no defensible distinct purpose; preserve redirects and update the legacy matrix.

## Acceptance criteria

- Service and guide have unmistakably different intent.
- No new synonym page is created without evidence.
- Existing URLs and legacy redirects are preserved.
- Claims and case links are specific and approved.
- Metadata, schema, H1, sitemap, images, links, tracking, and responsive QA pass.
- `pnpm build`, `pnpm lint`, and `pnpm seo:check` pass.
